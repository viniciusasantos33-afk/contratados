# **App Name**: Contratados

## Core Features:

- Multiple Pages: Implement multiple pages using Next.js routing.
- Home Page: Design a home page replicating the provided image's layout and elements, including the logo, text, and figures.
- Navigation Bar: Implement a responsive navigation bar with menu and eye icon.
- Animated Starry Background: Create an animated starry background effect, with subtly twinkling stars to simulate a night sky.

## Style Guidelines:

- Background color: Black (#000000) to create a stark, oppressive atmosphere.
- Primary color: White (#FFFFFF) for text and figures to maximize contrast and readability.
- Accent color: Red (#FF0000) for lines and highlights, symbolizing danger and urgency.
- Font: 'Arial' sans-serif font for a rough, unrefined, and intentionally jarring feel.
- Use a centralized layout for the main content, maintaining a balanced and slightly claustrophobic feel to enhance the horror aesthetic.
- Implement animations that mimic old CRT TVs or dial-up internet, with deliberate slowness, stuttering, and glitch effects to create unease.
